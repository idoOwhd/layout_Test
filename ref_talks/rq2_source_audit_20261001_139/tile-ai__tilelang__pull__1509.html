This pull request removes the usage of swizzled memory layouts and related annotations throughout the codebase, simplifying tensor allocation and layout management. It also makes minor improvements to variable allocation and thread binding in some kernels. These changes help streamline the code and reduce unnecessary complexity around layout specification.

Memory layout and annotation simplification:

  • Removed all calls to T.annotate_layout and the use of make_swizzled_layout for shared tensors in convolution, attention, and casting examples, as well as benchmark scripts. This affects files such as example_conv_analyze.py, example_convolution.py, example_convolution_autotune.py, example_gqa_sink_bwd_bhsd.py, example_gqa_sink_fwd_bhsd_wgmma_pipelined.py, example_mha_sink_bwd_bhsd.py, example_mha_sink_fwd_bhsd.py, example_mha_sink_fwd_bhsd_wgmma_pipelined.py, example_deepseek_mla/example_mla_decode.py, example_deepseek_mla/example_mla_decode_paged.py, and example_deepseek_mla/example_mla_decode_persistent.py.   • Removed imports of make_swizzled_layout and tilelang.layout where they are no longer needed, further cleaning up the code. [1] [2] [3] [4] [5] [6]

Tensor allocation and scope changes:

  • Updated tensor allocation in benchmark_mamba_chunk_scan.py to remove the explicit scope="shared" and scope="shared.dyn" parameters, using simpler allocation calls instead.

Kernel and utility improvements:

  • Changed thread binding in tilelang_bitnet_158_int8xint2_prefill.py to use T.get_thread_binding(0) instead of T.thread_binding(0, threads, "threadIdx.x"), simplifying thread management.

  • Improved variable allocation in example_group_per_split_token_cast_to_fp8.py by replacing fragment allocation for row_offset with a simple scalar variable, and updated its usage accordingly.

Miscellaneous:

  • Adjusted the logic in get_bwd_configs() in example_gqa_sink_bwd_bhsd.py to always return the default configuration for SM version 90 and above, removing the exception for unsupported versions.
