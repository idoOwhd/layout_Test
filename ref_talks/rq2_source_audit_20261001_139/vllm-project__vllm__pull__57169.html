Purpose

Pick #55219 to refactor the GLM-5.3-Flash KV layout.

This PR preserves @ivanium's original commits and adds three follow-ups:

  • Propagate physical block strides to sparse-MLA/indexer metadata builders
    in the model runner, MRv2, and speculative proposer paths, ensuring packed
    blocks use their physical stride.
  • Add regressions for packed kpool, sparse MLA, and DeepGEMM page addressing.
  • Use the existing block_stride_alignment allocator contract and remove the
    duplicate kernel_page_rows plumbing and inference.

Validation

Evaluated GLM-5.3-Flash on GB200 using the full 5-shot GSM8K dataset (1,319 questions, temperature 0).

  • TP4 baseline: 0.9121
  • NIXL P/D TP4 prefill + TP4 decode with CPU staging: 0.8916, 0.9121
  • Mooncake P/D, TP4 prefill + TP4 decode after the packed-Mamba payload fix: 0.9136,
