Summary

Fixes #54710.

Pipeline-parallel workers can expose different KV-cache layout lists when
their local layers use different attention backends. Requiring those lists to
be byte-for-byte identical rejects valid hybrid models even when all workers
share a compatible layout.

Resolve the ordered intersection of the worker lists, preserving the first
worker's preference order. A ValueError is still raised when the lists are
truly disjoint. The existing mixed-shape, explicit-layout, and connector
selection logic then operates on the common candidates as before.

No open or historical PR references #54710 or this specific worker-layout
intersection fix (checked immediately before submission).

Validation

  • pre-commit run --files vllm/v1/attention/backends/utils.py tests/v1/attention/test_backend_per_kind.py
  • ruff check and ruff format --check for the changed files
  • python -m py_compile vllm/v1/attention/backends/utils.py tests/v1/attention/test_backend_per_kind.py
  • git diff --check
  • Added CPU-level tests for compatible and disjoint worker layout sets.

The targeted pytest process could not complete in this Apple Silicon
environment because the repository's test bootstrap waits while importing an
optional runtime dependency. The reported PP/hybrid scenario should be covered
by the project's multi-GPU CI.

AI assistance was used for repository scouting and implementation. The human
submitter reviewed the complete diff and validation before opening this PR.
