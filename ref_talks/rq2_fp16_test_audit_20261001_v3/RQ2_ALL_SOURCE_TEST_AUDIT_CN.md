- PR/issue 按大小写归一的 repo+number 去重；同一 PR 的多次引用/issue 路径不增加样本数。

- native 原实现、FP16 mechanism analogue、legacy supporting probe 分开计数。
- AMD/XPU/NPU、TMA/TMEM、新架构或多卡依赖明确标 blocked，不用 CUDA reference 填成功。
